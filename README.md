# Campus Safe Haven

Hello. Hey can you build me a game as a boy? Let me tell you a story. Every boy thinks, in the popular story, that if ever a terrorist group attacks the college or school of any version, the person who is thinking of the idea will become the hero, kill all the terrorists, and become the hero.

With this thing can you build me a game where our college, SUIIT Sambalpur Purla, with all of the campus, will be the game area? A person who is thinking will be the main character and every boy, every student, and all are in the college. In the game the terrorists will attack our college and then the main character will fight. He has to think where the students are and where the teachers are. They have to think, plan, and then react. In this thing either the main character has to kill all the terrorists to win the match or securely make all the students and teachers escape so that they can win.

Can you create a game on our college theme with playing simulators and all the game engines and all? If you can build that I'll be so fucking happy. Can you just surprise me by building this? That's it.
